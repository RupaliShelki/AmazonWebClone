About
This project is a front page clone of Amazon’s website, created purely with HTML and CSS to practice layout, styling, and responsive design. It replicates the main navigation bar, search panel, hero section, product categories, and footer.

*Features
-Responsive navigation bar with logo, location, search bar, account options, and cart icon.
<br>
-Dropdown-like search category selector (static for practice).
-Hero section with background image and a promotional message.
-Shop categories displayed as grid boxes with images and titles.
-Footer with multiple informational links and branding.

*Technologies Used
HTML5: For semantic structure and content.
CSS3: For styling, layout using Flexbox and responsive design techniques.
Font Awesome: Used for icons like location, search, cart, and menu bars to enhance UI without custom images.
External CSS via CDN: Efficient and quick to load fonts and icons.

*Why I Used These
-Flexbox layout: Provides a flexible, responsive structure for navbar, shop grid, and footer.
-Background images with CSS: To keep the HTML clean and separate content from presentation.
-Font Awesome icons: To add professional-looking icons easily without creating custom graphics.
-Separate CSS file (style.css): For maintainability and reusability of styles.
-Semantic HTML elements (header, footer): For better accessibility and SEO.
-Hover effects on interactive elements: To improve user experience and visual feedback.

*What I Learned
-How to recreate a complex layout like Amazon’s homepage using only HTML and CSS.
-Using Flexbox for horizontal and vertical alignment.
-Handling images as background elements for product boxes.
-Linking external resources like icon libraries.
-Structuring a large CSS file with comments for maintainability.

*How to Run
-Clone or download the repository.
-Open index.html in any modern web browser.
-Ensure assets (images) are in the correct assets/ folder path.
